AI vs Machine Learning vs Deep Learning

Understand how computers become intelligent

1. Artificial Intelligence (AI)

AI is the broader field of creating machines that perform tasks requiring intelligence, such as reasoning, planning, problem-solving and decision-making.

Example: Rule-based traffic signal

Input Traffic signal sensor detects vehicles.
Predefined rule If traffic is high, extend green light.
Vehicle Data
→
IF-ELSE Rules
→
Decision

Notice: This example uses predefined rules. It does not learn from historical data. Rule-based systems are one traditional approach within AI.

2. Machine Learning (ML)

Machine Learning is a subset of AI. It learns patterns from historical data instead of requiring a programmer to manually write every decision rule.

Example: Predicting house prices

Training Data 500 sq ft = 15 lakh
1000 sq ft = 30 lakh
1500 sq ft = 45 lakh
New Input House size = 1200 sq ft
Historical Data
→
ML Algorithm
→
Learned Model

What has the computer learned?

From the sample data, it learns a simple relationship: Price = House Area × 0.03 lakh.

3. Deep Learning (DL)

Deep Learning is a subset of Machine Learning. It uses artificial neural networks with multiple layers to learn complex patterns from data.

Example: Recognizing handwritten digits

Input An image of handwritten digit 7.
Output Computer predicts digit 7.

Neural Network Architecture

Input
Hidden 1
Hidden 2
Output

The layers learn increasingly useful representations. Early layers may detect simple visual features, while later layers can combine them into more complex patterns.
