3. How does an individual neuron work?

A neuron receives multiple inputs. Each input is multiplied by its corresponding weight.

Step 1: Weighted Sum
z = (x₁ × w₁) + (x₂ × w₂) + b

Step 2: Activation Function
a = σ(z)

Sigmoid Activation
σ(z) = 1 / (1 + e-z)

Here:

  • x = Input value
  • w = Weight of connection
  • b = Bias
  • z = Weighted sum
  • a = Activated output
