Three ways a machine learns

Same computer, different kind of feedback. Pick a tab and run the demo.

Learning from labeled examples

Every training point comes with the right answer. The model adjusts itself until its guesses match those answers, then predicts labels for points it has never seen.

Label A Label B

Finding structure without answers

The data has no labels at all. The model looks for patterns on its own, here by grouping points that sit close together (k-means clustering).

Learning from rewards by trial and error

An agent takes actions and gets rewards or penalties. Nobody tells it the right move, so it must discover which choices pay off over time (Q-learning).
